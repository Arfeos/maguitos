● Descripción

El proyecto consiste en una práctica para crear un shooter 3D. Nosotros hemos decidido hacer un shooter de magos en lugar del clásico con armas de fuego, así que te adentrarás en la piel de un mago el cual, ansioso de poder, eliminó al resto de magos.
Más tarde, usó un hechizo de clonación para tener un ejército propio pero pronto, las varitas y grimorios empezaban a escasear por lo que se erigió una batalla para obtener las de otros clones. Sé el último en pie para demostrar que eres el original y el único de posser tan apreciados artefactos. (Multiplayer mode)
Por si fuera poco, empezaron a sentirse atraídas otras criaturas por el poder y maná emitido, por lo que comenzaron a invadir nuestro reino. Por ahora sólo llegaron los slimes, así que ármate con los hechizos que prefieras en tu torre, deberás salir a enfrentarlos y aguantar mientras puedas para proteger tu ansiado poder. (Singleplayer mode) 

● Controles

WASD - Movimiento por el escenario
Espacio - Salto
V - Agacharse
E - Interactuar/coger objetos y hechizos
F - Encencer/apagar farol si se ha recogido
Mover el ratón - Mover la cámara
Clic izquierdo del ratón - Lanzar hechizos
Clic derecho del ratón - Hacer zoom (como usar una mirilla)
Teclas de números 1 o 2 - Cambiar entre hechizo principal y secundario

● Mecánicas

Aparte de las que proporcionan los controles cuenta con:
  - Creación de perfiles con ajustes configurables y almacenados independientemente para mantener la configuración personalizada de cada usuario
  - Acceso a los ajustes desde distintas pantallas del juego, incluyendo in-game
  - Invocación de enemigos cada cierto tiempo para el modo hordas de slimes
  - Contador de rondas y resumen final al ser derrotado en las hordas
  - Scoreboard que recoge el nombre, los puntos y si se ha atacado, para hacer un ranking entre los usuarios guardados locales
  - Sincronización entre host y cliente para partidas del modo arena del multijugador
  - Steps para mostrar en un popup los pasos que guian al jugador a través del tutorial y reusable para mostrar los pasos de una misión u objetivos a conseguir en los modos de juego si se quiere
  - Distintos tipos de hechizos que pueden ser ampliables. Actualmente se dispone de hechizos tipo spherecast y raycast
  - Hechizos ya preparados que pueden ser ampliados con unos sencillos pasos gracias a scriptable objects


● Instrucciones de ejecución

1. Descargar o clonar este repositorio
2. Si se ha descargado tendremos un archivo comprimido. Se descomprime para poder usarlo
3. Descargar Unity Hub para poder instalar Unity e importar proyectos
4. Importar el proyecto descomprimido o clonado
5. Uso de Unity 6 para poder abrir y entrar al proyecto (la versión exacta necesaria se ve al lado del proyecto importado)
6. Buscar en la parte de abajo llamada "assets" la carpeta "Scenes", entrar a "UI", "Initials" y ejecutar la escena "Initial_Language"
7. Arriba del todo del programa aparece un botón con el símbolo de play, lo presionamos para entrar al modo de juego y poder jugar

Otra manera de ahorrar los pasos anteriores es presionar ctrl+B para hacer lo llamado "build del juego", lo que nos creará un ejecutable en una carpeta donde le indiquemos y directamente se abrirá cada vez que ejecutemos el ejecutable.
