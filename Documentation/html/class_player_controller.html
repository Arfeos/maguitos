Descripción detallada

Componente de Unity encargado de gestionar el control completo del jugador. Controla el movimiento, rotación de cámara, salto, agacharse, animaciones, sonidos, pausa, cambio de hechizos y daño recibido. Se comunica con múltiples servicios como ICharacterService, IEventService, IAudioService, IPauseService y IProfileService. También utiliza PlayerInputManager para gestionar las entradas del jugador.
