Descripción detallada

Interfaz encargada de definir las operaciones necesarias para gestionar un sistema de eventos basado en publicación y suscripción. Proporciona los métodos necesarios para enviar, registrar y eliminar eventos derivados de GameEventBase. Es implementada por EventService para facilitar la comunicación desacoplada entre distintos sistemas del proyecto.
