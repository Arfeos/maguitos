Descripción detallada

Servicio encargado de gestionar toda la lógica relacionada con el personaje, incluyendo salud, maná, inventario de hechizos, selección de habilidades y estados especiales. Se comunica con IEventService para notificar cambios y utiliza objetos SpellBase para administrar los hechizos del jugador.
