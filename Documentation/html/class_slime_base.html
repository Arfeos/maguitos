Métodos públicos

virtual void Hit (float damage)
 Recibe un golpe, reduce la vida y activa la barra de vida. Si la vida llega a 0 o menos, llama a Die. No tiene efecto si el slime ya está muerto.

Métodos protegidos

virtual void Awake ()
 Resuelve las dependencias de servicios desde el contenedor de la aplicación.
virtual void Start ()
 Inicializa referencias de componentes, configura la barra de vida y los valores de estado.
virtual void Update ()
 Cada frame busca al jugador si falta la referencia, comprueba si el slime está muerto y lanza la corrutina de cooldown de acciones si no hay ninguna en curso.
virtual void Attack ()
 Lógica de ataque específica del enemigo. La base reproduce el AttackSound; las subclases deben llamar a base.Attack().
virtual void Move (float distanceToPlayer)
 Lógica de movimiento específica del enemigo. La base reproduce el JumpSound; las subclases deben llamar a base.Move().
virtual void OnUpdate ()
 Se llama cada frame desde Update (ya filtrado por null y muerte). Sobreescribe para añadir lógica extra (ej: CheckGrounded, DetectLanding). La base ya llama a CheckState.
virtual void OnDeath ()
 Se llama justo antes de iniciar la disolución del objeto. La base suma puntuación e intenta spawnear orbes según sus porcentajes configurados. Sobreescribe para añadir lógica extra al morir (drops, efectos, eventos, etc.).
void CheckState ()
 Evalúa si el slime debe atacar o moverse en función de la distancia al jugador. Solo actúa si _nextActionTime es true.
float CalculateDistance ()
 Calcula la distancia plana (ignorando el eje Y) entre el slime y el jugador.
virtual void Die ()
 Ejecuta la secuencia de muerte: detiene corrutinas, activa la animación de muerte, llama a OnDeath e inicia la disolución con retardo.
virtual IEnumerator DissolveAfterDelay ()
 Corrutina que espera delayBeforeStart segundos, luego aplica el shader de disolución a todos los renderers hijos y anima el progreso hasta destruir el objeto.
void CreateOrbsByPercent (float Percent, GameObject Orb)
 Comprueba la probabilidad y, si se cumple, instancia el orbe indicado cerca del slime.
bool CheckPercentSpawn (float percentToCheck)
 Genera un número aleatorio entre 0 y 100 y lo compara con percentToCheck .
void InstantiateOrb (GameObject Orb)
IEnumerator ActionCooldownRoutine ()
 Corrutina que bloquea nuevas acciones durante attackCooldown segundos y después las habilita de nuevo, limpiando la referencia _actionCoroutine.

Descripción detallada

Clase base para todos los slimes del juego. Gestiona vida, barra de vida, disolución al morir y el ciclo de acciones. Las subclases implementan Attack y Move con su comportamiento específico.
