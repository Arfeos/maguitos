Descripción detallada

MonoBehaviour que controla el comportamiento de un blanco del rango de tiro del tutorial. Implementa IHittable para reaccionar a los impactos, se mueve horizontalmente rebotando en los límites y suma puntos al jugador cuando el juego está activo.
